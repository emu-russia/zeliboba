# artwork — графика zeliboba

Здесь лежат логотип, иконка и портрет талисмана эмулятора. Всё содержимое
каталога генерируется одним скриптом, поэтому арт можно перерисовать или
подправить палитру одной командой, а не правкой SVG руками:

```bash
python3 artwork/make_artwork.py     # нужны fonttools, cairosvg, Pillow
```

## Персонаж

Имя эмулятора — это **Зелибоба**, синий пушистый дух двора из российской
версии «Улицы Сезам» (`Улица Сезам`, НТВ/СТС, 1996–2007), куклу построил
Эд Кристи. Портрет нарисован по описаниям и кадрам из первоисточников:

* **Синяя пушистая шкура** — «большая шевелящаяся куча мульчи» (Эд Кристи).
  Изначально Кристи задумывал Зелибобу как *лешего* с зелёно-бурой шерстью
  «как листва и опавшие листья»; по просьбе российских продюсеров цвет
  сменили на синий — «более абстрактный» и сильнее ассоциирующийся с духами.
* Шкура висит **длинной мантией со шлейфом и рукавами**, в ней вкраплены
  тёмно-синие и рыжие пряди.
* Он **слегка напоминает гончую**: длинная морда и исключительный нюх (им он
  чует запахи, погоду, музыку и настроение).
* Ушей нет — голова целиком уходит в пух.
* Большие белые глаза, над каждым — своя **чёрная бровь-горка**; зрачки посажены
  низко и ближе к носу — он словно смотрит на собственный нос.
* **Нос-капля**: узкий у переносицы, между глазами, и округлый книзу. Под
  ним — большой открытый рот с оранжевым языком.
* Золотисто-оранжевые руки и ноги, **белые кроссовки** и огромный
  **разноцветный галстук** — Зелибоба их коллекционирует.

Тело намеренно не рисуется: в эмуляторе лицо работает и как иконка, и как
портрет на баннере.

Источники описания: [Улица Сезам — Википедия](https://ru.wikipedia.org/wiki/Улица_Сезам)
и [Zeliboba — Muppet Wiki](https://muppet.fandom.com/wiki/Zeliboba).
Кадры и фотографии куклы — собственность Sesame Workshop / «Улицы Сезам»; они
использовались **только как наглядный референс** и в репозиторий не попадают.
Весь арт здесь — оригинальная векторная перерисовка, а не копия кадра.

## Что в каталоге

| Файл | Что это |
|---|---|
| `make_artwork.py` | генератор: единственный источник правды для всего остального |
| `zeliboba-face.svg` | портрет: лицо на прозрачном фоне |
| `zeliboba-icon.svg` | иконка приложения: лицо на тёмной плитке |
| `zeliboba-logo.svg` | горизонтальный логотип для тёмного фона |
| `zeliboba-logo-light.svg` | то же для светлого фона |
| `zeliboba-logo-compact.svg` | то же без подписи |
| `zeliboba-logo-stacked.svg`, `…-light.svg` | вертикальный логотип |
| `zeliboba-wordmark.svg`, `…-light.svg` | только надпись |
| `zeliboba-banner.svg` | баннер 1600×560 для README |
| `zeliboba.ico` | иконка Windows: 16, 20, 24, 32, 40, 48, 64, 96, 128, 256 |
| `png/` | растровые версии всего перечисленного |
| `png/zeliboba-icon-sizes.png` | контрольный лист: как знак читается в 16…256 px |
| `png/zeliboba-icon-16…1024.png` | иконка по размерам |

Иконка попадает в сборку двумя путями:

* `artwork/zeliboba.ico` подключается ресурсным скриптом
  (`src/zeliboba.rc`, `src/ui/zeliboba_ui.rc`) — это иконка `.exe` в проводнике,
  на панели задач и в Alt-Tab;
* `src/ui/zeliboba_icon_pixels.h` — та же иконка 64×64 как массив ARGB8888,
  который SDL3-фронтенд ставит окну через `SDL_SetWindowIcon`.

## Шрифт

Надпись «zeliboba» набрана **Lato Black**, подписи — Lato Semibold/Medium.
Глифы в этом каталоге хранятся **кривыми** (`fonttools` → path), поэтому SVG
никуда не тянет файл шрифта и одинаково выглядит везде. Lato распространяется
по лицензии SIL OFL 1.1; в репозиторий положены только контуры букв.

## Мелочи, о которые легко споткнуться

* Каждый контур буквы обязан попадать в **один** `<path>`: если вывести контуры
  отдельными путями, внутренности `e`, `o`, `b`, `a` заливаются сплошным
  цветом — счётчики не вырезаются. Отсюда `fill-rule="evenodd"`.
* Ресурсный компилятор разрешает путь к `.ico` относительно самого `.rc`,
  поэтому в `src/ui/zeliboba_ui.rc` стоит `..\..\artwork\zeliboba.ico`.
* Для размеров меньше 24 px включён упрощённый вариант знака (меньше прядей,
  крупнее глаза и нос) — иначе иконка превращается в кашу.
